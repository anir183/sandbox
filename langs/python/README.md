# Python Language Roadmap
Roadmap for personal use. Generated by ChatGPT.

### Chapter 1 — Execution model and program structure
- Interpreter, source files, modules, scripts, REPL, and __main__.
- Indentation, statements, comments, naming conventions, and code blocks.
- Running scripts, command-line arguments, and python -m.
- Imports, package structure, and virtual environments at a basic level.
> Tribal knowledge: indentation defines blocks. Python is dynamically typed, but not weakly typed; values have types, and incompatible operations can raise TypeError.

### Chapter 2 — Variables, built-in types, and operators
- Names and object references; assignment and rebinding.
- int, float, bool, str, NoneType, complex numbers.
- Arithmetic, comparison, logical, bitwise, identity, membership, and assignment operators.
- is vs ==, truthiness, type conversion, type, isinstance.
- Integer division //, modulo %, exponentiation **, floor division with negatives.
> Tribal knowledge: Python integers have arbitrary precision; / returns a float; // floors toward negative infinity; and and or return operands, not necessarily booleans.

### Chapter 3 — Control flow and iteration
- if, elif, else, for, while, break, continue, pass.
- range, enumerate, zip, reversed.
- match / case pattern matching.
- Truth-value testing, chained comparisons, loop else.
- Nested iteration, early returns, and guard clauses.
> Tribal knowledge: range(stop) excludes stop; enumerate is usually cleaner than maintaining an index manually; zip stops at the shortest iterable by default.

### Chapter 4 — Functions, arguments, and scope
- def, return, docstrings, local/global/nonlocal scope.
- Positional, keyword, default, and keyword-only arguments.
- *args, **kwargs, unpacking, and argument passing.
- Recursion, closures, lambdas, first-class functions.
- Type hints, return annotations, and function contracts.
> Tribal knowledge: default argument values are evaluated once when the function is defined. Avoid mutable defaults like def f(items=[]):; use None instead.

### Chapter 5 — Lists, tuples, ranges, and sequence behavior
- Lists, tuples, range, indexing, negative indexing, and slicing.
- List methods: append, extend, insert, pop, remove, sort, reverse.
- Nested lists, shallow copies, list multiplication, aliasing.
- Tuple unpacking, multiple assignment, swapping, and immutable sequences.
- sorted, reversed, min, max, sum, any, all.
> Tribal knowledge: list.sort() modifies the list and returns None; sorted() returns a new list. Avoid [[0] * m] * n for independent matrix rows because it aliases the same inner list.

### Chapter 6 — Strings and text processing
- String immutability, indexing, slicing, concatenation, and iteration.
- split, join, strip, replace, find, startswith, endswith.
- lower, upper, casefold, isalpha, isdigit.
- f-strings, format specifications, ord, chr.
- Raw strings, escape sequences, Unicode, and regular expressions via re.
> Tribal knowledge: strings are immutable; use "".join(parts) for joining many pieces; split() without a separator handles runs of whitespace differently from split(" ").

### Chapter 7 — Dictionaries and sets
- dict, set, frozenset, membership, iteration, and hashing.
- Dictionary operations: get, setdefault, update, pop, items, keys, values.
- Set operations: union, intersection, difference, symmetric difference.
- Dictionary/set comprehensions, frequency counting, deduplication.
- collections.Counter, defaultdict, OrderedDict basics.
> Tribal knowledge: dictionary insertion order is guaranteed in modern Python; sets are unordered. Dictionary keys must be hashable. A missing dictionary key raises KeyError unless handled appropriately.

### Chapter 8 — Comprehensions and idiomatic Python
- List, dictionary, and set comprehensions.
- Generator expressions, unpacking, starred expressions.
- Conditional expressions and assignment expressions (:=) at a basic level.
- any, all, sum, min, max, sorted with key=.
- Readable transformations vs nested loops.
> Tribal knowledge: comprehensions can replace simple map/filter patterns, but deeply nested comprehensions often reduce readability.

### Chapter 9 — Iterables, iterators, and generators
- Iterable vs iterator; iter, next, StopIteration.
- Generator functions, yield, generator expressions.
- Lazy evaluation, iterator exhaustion, and itertools.
- map, filter, zip, enumerate and their iterator behavior.
- Custom iteration protocol basics: __iter__, __next__.
> Tribal knowledge: many built-ins return iterators rather than lists. Convert to list(...) only when you need materialized results or repeated traversal.

### Chapter 10 — Standard library for DSA
- collections: deque, Counter, defaultdict.
- heapq: min-heaps, heappush, heappop, heapify, nlargest, nsmallest.
- bisect: bisect_left, bisect_right, insertion points.
- itertools: chain, product, combinations, permutations, accumulate.
- math: gcd, lcm, isqrt, inf, ceil, floor, comb, perm.
- functools: lru_cache, cache, cmp_to_key, reduce.
> Tribal knowledge: heapq is a min-heap; use negated priorities for a max-heap when appropriate. bisect finds positions in sorted sequences; it doesn't sort the sequence for you.

### Chapter 11 — Classes and object-oriented Python
- Classes, instances, __init__, self, instance vs class attributes.
- Methods, @classmethod, @staticmethod, properties.
- Inheritance, overriding, composition, method resolution order.
- Dunder methods: __repr__, __str__, __eq__, __lt__, __hash__.
- Dataclasses, frozen dataclasses, enums, and basic protocols.
> Tribal knowledge: Python doesn't have a Java-style private access modifier; leading underscores signal internal use. Instance attributes can shadow class attributes, and mutable class attributes may be shared between instances.

### Chapter 12 — References, mutability, and Python's data model
- Object identity vs equality: is vs ==.
- Mutable vs immutable objects, aliasing, shallow vs deep copy.
- Names, references, rebinding, and argument-passing behavior.
- Hashability and the equality/hash contract.
- Truthiness, None, singleton objects, and object lifetime.
> Tribal knowledge: assignment doesn't copy an object. Lists and dictionaries are mutable; strings, tuples, integers, and frozensets are immutable, although a tuple can contain mutable objects.

### Chapter 13 — Exceptions and defensive programming
- try, except, else, finally, raise.
- Exception types, custom exceptions, exception chaining.
- assert, input validation, defensive checks.
- KeyError, IndexError, ValueError, TypeError, AttributeError, RecursionError.
- Context managers and with.
> Tribal knowledge: catch specific exceptions rather than broadly swallowing errors. Assertions are for internal invariants, not validation that must always run.

### Chapter 14 — Files, input/output, and serialization
- open, read, readline, write, readlines, file iteration.
- Context managers: with open(...).
- File modes, paths, encodings, and pathlib.Path.
- Standard input/output, sys.stdin, sys.stdout, input, print.
- json, csv, pickle basics and serialization caveats.
> Tribal knowledge: use with to close files reliably; specify encoding when appropriate; never unpickle untrusted data.

### Chapter 15 — Modules, packages, environments, and tooling
- Import semantics, module search path, __name__ == "__main__".
- Standard-library modules vs third-party packages.
- Virtual environments, pip, package versions, pyproject.toml basics.
- sys.argv, environment variables, running modules with -m.
- Basic testing with unittest or pytest, linting, and formatting.
> For LeetCode, you generally don't need dependencies or project scaffolding. Learn enough to run Python programs reliably outside the platform.

### Chapter 16 — Complexity and performance behavior
- Big-O for lists, dictionaries, sets, sorting, and common built-ins.
- Amortized cost of list append and dynamic-array resizing.
- Membership: list scan vs set/dictionary lookup.
- String concatenation, slicing copies, comprehensions, and generator trade-offs.
- Recursion depth, call overhead, timeit, and memory considerations.
> Tribal knowledge: average dictionary/set operations are typically O(1), but worst-case behavior can differ. Python's recursion limit can matter on deep DFS or recursive DP.

### Chapter 17 — Advanced Python features and concurrency
- Type hints, typing, generics, Protocol, TypedDict, unions, optional values.
- Decorators, closures, descriptors, and context-manager protocol.
- Async functions, async / await, and asyncio basics.
- Threads, multiprocessing, the Global Interpreter Lock (GIL), and concurrency trade-offs.
- CPython implementation details, reference counting, garbage collection.
> For interviews, learn basic type annotations and recursion limits early; defer descriptors, advanced typing, async, and concurrency until your target role requires them.
