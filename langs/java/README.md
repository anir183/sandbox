# Java Language Roadmap
Roadmap for personal use. Generated by ChatGPT.

### Chapter 1 — Java execution model and program structure
- JDK vs JRE vs JVM; source code, bytecode, compilation, and execution.
- javac, java, main method, class declarations, packages, and imports.
- Statements, blocks, semicolons, comments, naming conventions.
- Compile-time errors vs runtime exceptions.
- Basic command-line compilation and running programs.
> Know: Java is statically typed and normally compiles to JVM bytecode.

### Chapter 2 — Variables, types, operators, and expressions
- Primitive types: byte, short, int, long, float, double, char, boolean.
- Reference types, declarations, initialization, scope, and final.
- Arithmetic, relational, logical, bitwise, shift, assignment, ternary, and instanceof operators.
- Integer division, numeric promotion, widening/narrowing conversions, casts, overflow.
- == vs .equals(), operator precedence, short-circuit evaluation.
> Tribal knowledge: int overflow wraps around; integer division truncates toward zero; long literals often need an L suffix.

### Chapter 3 — Control flow and program logic
- if, else, switch, switch expressions, for, enhanced for, while, do-while.
- break, continue, return, labeled statements.
- Nested loops, loop invariants, early exits, and guard clauses.
- Scanner, BufferedReader, System.out, and basic input parsing.
> Tribal knowledge: Java conditions require a boolean; unlike Python, integers are not implicitly truthy or falsy.

### Chapter 4 — Methods and parameter passing
- Method signatures, return types, void, parameters, arguments, and overloading.
- Pass-by-value, scope, local variables, recursion, and stack frames.
- static methods, varargs (...), method references (preview later), and visibility.
- Decomposition, helper methods, and contracts.
> Tribal knowledge: Java is always pass-by-value. When passing an object, the reference value is copied—not the object itself.

### Chapter 5 — Arrays and multidimensional arrays
- Declaration, allocation, initialization, indexing, and traversal.
- int[], int[][], jagged arrays, .length, array references.
- Arrays.sort, Arrays.fill, Arrays.copyOf, Arrays.equals, Arrays.binarySearch.
- System.arraycopy, Arrays.deepToString, array copying and aliasing.
- Frequency arrays, matrix traversal, prefix sums, and two-dimensional grids.
> Tribal knowledge: arrays have fixed length; arr.length is a field, not a method. Java initializes array elements to default values.

### Chapter 6 — Strings, characters, and text processing
- String, char, Unicode, UTF-16 code units, and code points.
- Immutability, string literals, the string pool, and == vs .equals().
- length(), charAt(), substring(), indexOf(), contains(), split(), replace().
- StringBuilder, toCharArray(), String.valueOf(), Character utilities.
- String.format, printf, regular expressions through Pattern and Matcher.
> Tribal knowledge: repeated string concatenation in a loop can be costly; use StringBuilder. String.length() counts UTF-16 code units, not necessarily Unicode characters.

### Chapter 7 — Object-oriented programming
- Classes, objects, fields, methods, constructors, and this.
- Encapsulation, access modifiers, static members, initialization blocks.
- Inheritance, overriding, overloading, polymorphism, abstract classes.
- Interfaces, default methods, super, composition vs inheritance.
- Object methods: equals, hashCode, toString.
- Enums, nested classes, records, and immutable objects.
> Tribal knowledge: an overridden equals() must be consistent with hashCode() when objects are used as hash keys. Records are useful for simple data carriers.

### Chapter 8 — Collections Framework
- List, Set, Queue, Deque, Map, and the distinction between interfaces and implementations.
- ArrayList, LinkedList, HashSet, LinkedHashSet, TreeSet.
- HashMap, LinkedHashMap, TreeMap.
- ArrayDeque, PriorityQueue.
- Collections utilities, immutable collections, iteration, Iterator, ListIterator.
- Complexity, ordering guarantees, null behavior, and fail-fast iterators.
> Tribal knowledge: use ArrayDeque for most stacks and queues; PriorityQueue is a min-heap by default; HashMap does not guarantee iteration order.

### Chapter 9 — Generics, comparators, and custom ordering
- Generic classes, methods, type parameters, and bounded type parameters.
- T, E, K, V, wildcards, extends, super, and type erasure.
- Comparable, Comparator, compareTo, compare.
- Lambdas, comparator chaining, thenComparing, reversed, comparingInt.
- Sorting custom objects, pair-like structures, and multidimensional arrays.
> Tribal knowledge: comparator contracts matter; avoid subtraction-based comparisons such as a - b because integer overflow can break ordering.

### Chapter 10 — Essential standard-library utilities
- Math: abs, min, max, sqrt, pow, floor, ceil.
- Integer, Long, Character, Objects.
- Arrays, Collections, Comparator.
- BigInteger for arbitrary-precision integer arithmetic.
- Optional basics, StringJoiner, Random, SecureRandom distinctions.
- Parsing and conversion: Integer.parseInt, Long.parseLong, toString.
> Tribal knowledge: Math.abs(Integer.MIN_VALUE) remains negative due to overflow. Use long when constraints can exceed 32-bit integer range.

### Chapter 11 — Exceptions and error handling
- try, catch, finally, throw, throws.
- Checked vs unchecked exceptions, RuntimeException, Error.
- Custom exceptions, multi-catch, try-with-resources.
- Defensive validation, null handling, and exception propagation.
> Tribal knowledge: don't use exceptions for ordinary control flow. Understand NullPointerException, ArrayIndexOutOfBoundsException, and NumberFormatException.

### Chapter 12 — Functional Java and streams
- Functional interfaces: Predicate, Function, Consumer, Supplier.
- Lambdas, method references, and capturing variables.
- Stream pipelines: filter, map, flatMap, sorted, distinct, reduce, collect.
- Collectors, grouping, partitioning, and primitive streams.
- Side effects, laziness, and sequential vs parallel streams.
> Interview priority: understand lambdas and comparators well. Use streams when they improve clarity, but don't force them into algorithmic loops.

### Chapter 13 — Files, I/O, and serialization
- Path, Files, File, InputStream, OutputStream, readers and writers.
- BufferedReader, BufferedWriter, Scanner, PrintWriter.
- Character encodings, UTF-8, resource management.
- ObjectInputStream / ObjectOutputStream basics and serialization caveats.
- Reading input efficiently, token parsing, file paths, and exceptions.
> Interview priority: basic input/output is useful; advanced file handling is usually lower priority for LeetCode.

### Chapter 14 — Memory model and runtime behavior
- Stack frames, heap allocation, references, object lifetime, and garbage collection.
- Primitive vs reference semantics, aliasing, null references.
- Pass-by-value, shallow vs deep copying, immutability.
- Boxing and unboxing, wrapper caches, Integer comparisons.
- Basic JVM memory areas and garbage-collection concepts.
> Tribal knowledge: Integer a = 127; Integer b = 127; a == b can be true due to caching, but wrapper identity is not value equality. Use .equals() or compare primitive values.

### Chapter 15 — Packages, modules, and build tooling
- Packages, imports, classpath, module path, Java Platform Module System basics.
- public, package-private, protected, private.
- Source files, JARs, dependency management, Maven/Gradle basics.
- JDK versions, compiler flags, IDE vs command-line builds.
> For interview work, know how to compile and run a simple program and understand imports. Deep module-system knowledge can wait.

### Chapter 16 — Data-structure implementation patterns
- Implement a linked list, stack, queue, binary tree, trie, graph, and union-find.
- Adjacency lists, edge lists, matrices, and traversal state.
- Recursion, iterative traversal, custom nodes, sentinel nodes.
- Complexity trade-offs and API design.
> This chapter connects language fluency to DSA: implement at least the structures that built-in collections don't directly provide.

### Chapter 17 — Performance, concurrency, and advanced features
- Algorithmic bottlenecks, allocation, autoboxing overhead, and profiling basics.
- BigInteger, bit manipulation, BitSet, and numeric precision.
- Threads, synchronization, executors, concurrent collections, and Java Memory Model basics.
- Annotations, reflection, assertions, and modern Java language features.
> For DSA interviews, prioritize integer behavior, bit manipulation, and performance. Study concurrency deeply only when the role calls for it.
